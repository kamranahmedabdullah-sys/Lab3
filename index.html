How it is deployed

One service of each type, as covered in the lab manual.

SaaS

Odoo Inventory is hosted and updated by the vendor. Users log in through a browser and manage products, receipts and deliveries.

PaaS

Netlify builds and hosts this site straight from GitHub. There is no server to manage, only code and a build command.
